The porting itself was not difficult. Composite transparent areas onto a white background, convert to grayscale, shrink, then substitute each pixel with a character. I opened up the conversion through both an API and an agent tool. The agent side handled input validation automatically, but the API side did not. Over two rounds of review, I added safeguards one by one — external address validation, size limits, internal network blocking.
